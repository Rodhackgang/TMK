Installation Rapide

1

Créer un compte Tawk.to

Allez sur tawk.to et créez un compte gratuit en 2 minutes.

2

Récupérer votre Widget ID

Dans le dashboard, copiez votre Widget ID depuis les paramètres.

3

Configurer sur votre site

Collez votre Widget ID dans config/chat-config.php

4

C'est prêt !

Le widget s'affiche automatiquement sur toutes les pages de votre site.
