💻 EN LOCAL, LE CHAT FONCTIONNE ?
═══════════════════════════════════════════════════════════════════

✅ OUI, le chat Tawk.to fonctionne en local !

MAIS il faut :
  ✓ Une connexion internet active
  ✓ Un serveur PHP (XAMPP, WAMP, MAMP, etc.)
  ✓ Le fichier config/chat-config.php correctement configuré

❌ Le chat ne fonctionnera PAS si :
  ✗ Vous ouvrez directement le fichier HTML (file://)
  ✗ Vous n'avez pas de connexion internet
  ✗ Le fichier PHP n'est pas exécuté par le serveur

═══════════════════════════════════════════════════════════════════
🔍 VÉRIFICATIONS À FAIRE
═══════════════════════════════════════════════════════════════════

☐ 1. CONNEXION INTERNET
   → Vérifiez que vous êtes connecté à internet
   → Le widget Tawk.to doit télécharger un script en ligne

☐ 2. SERVEUR PHP EN MARCHE
   → XAMPP : Apache doit être démarré (bouton vert)
   → WAMP : L'icône doit être verte
   → MAMP : Les serveurs doivent être actifs

☐ 3. URL CORRECTE
   → Utilisez http://localhost/...
   → PAS file:///C:/...
   
   Exemples corrects :
   ✓ http://localhost/Foundation/index.php
   ✓ http://localhost:8080/Foundation/index.php
   ✓ http://127.0.0.1/Foundation/index.php

☐ 4. FOOTER INCLUS
   → Vérifiez que vos pages contiennent :
     <?php require './utils/footer.php'; ?>
   
   → À la fin de chaque page PHP

☐ 5. CONFIGURATION CORRECTE
   → Ouvrez : config/chat-config.php
   → Vérifiez :
     define('TAWK_ENABLED', true);
     define('TAWK_WIDGET_ID', '68e8cf7997f1e31950bd9bda');
     define('TAWK_WIDGET_KEY', '1j76mktf9');

☐ 6. CACHE DU NAVIGATEUR
   → Appuyez sur Ctrl + F5 (Windows)
   → Ou Cmd + Shift + R (Mac)
   → Cela recharge la page sans cache

═══════════════════════════════════════════════════════════════════
🐛 DÉBOGUER AVEC LA CONSOLE
═══════════════════════════════════════════════════════════════════

1. Ouvrez votre page dans le navigateur
2. Appuyez sur F12 (ouvre les outils développeur)
3. Allez dans l'onglet "Console"
4. Rechargez la page (F5)

Que voir dans la console :

✅ SI LE CHAT FONCTIONNE :
   🔧 Tawk.to Widget Loading...
   Widget ID: 68e8cf7997f1e31950bd9bda
   Widget Key: 1j76mktf9
   ✅ Widget Tawk.to chargé avec succès !

❌ SI ERREUR :
   • "net::ERR_INTERNET_DISCONNECTED"
     → Pas de connexion internet
   
   • "404 Not Found"
     → Mauvais Widget ID
   
   • "Mixed Content"
     → Problème HTTP/HTTPS
   
   • Aucun message
     → Le script n'est pas chargé (vérifier footer.php)

🔄 SOLUTION : INTÉGRATION DIRECTE
═══════════════════════════════════════════════════════════════════

Si le système PHP ne fonctionne pas, vous pouvez intégrer
le chat directement dans utils/footer.php :

AVANT </body>, ajoutez :

<!--Start of Tawk.to Script-->
<script type="text/javascript">
var Tawk_API=Tawk_API||{}, Tawk_LoadStart=new Date();
(function(){
var s1=document.createElement("script"),s0=document.getElementsByTagName("script")[0];
s1.async=true;
s1.src='https://embed.tawk.to/68e8cf7997f1e31950bd9bda/1j76mktf9';
s1.charset='UTF-8';
s1.setAttribute('crossorigin','*');
s0.parentNode.insertBefore(s1,s0);
})();
</script>
<!--End of Tawk.to Script-->

Sauvegardez et testez !

🌐 TESTER SUR UN SERVEUR EN LIGNE
