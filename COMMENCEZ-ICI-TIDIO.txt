🚀 ÉTAPE 1 : CRÉER VOTRE COMPTE (2 minutes)
═══════════════════════════════════════════════════════════════════

1. Allez sur : https://www.tidio.com

2. Cliquez sur le bouton vert "Start Free Trial"

3. Remplissez :
   Email : votre-email@example.com
   Mot de passe : (votre mot de passe)
   Site web : tmkfoundation.org

4. Vérifiez votre email et cliquez sur le lien

═══════════════════════════════════════════════════════════════════
🤖 ÉTAPE 2 : CONFIGURER LE BOT IA (5 minutes)
═══════════════════════════════════════════════════════════════════

Une fois connecté au dashboard Tidio :

1. Menu gauche > "Chatbots"
2. Cliquez "Add Chatbot"
3. Choisissez "Lyro AI Chatbot" (c'est l'IA !)
4. Nommez-le : "Assistant TMK"
5. Langue : Français

Puis ajoutez ces questions (copiez-collez) :

   orphelinats, hôpitaux, écoles et centres d'accueil.

R: WhatsApp : +243 978 219 845
   Email : contact@tmkfoundation.org
   Site : www.tmkfoundation.org

   à contact@tmkfoundation.org pour les modalités de don.

🎨 PERSONNALISER (2 minutes)
═══════════════════════════════════════════════════════════════════

Settings > Appearance :
  - Couleur : #d4202c (Rouge TMK)
  - Position : Bottom Right

═══════════════════════════════════════════════════════════════════
📋 ÉTAPE 3 : RÉCUPÉRER VOTRE CODE (1 minute)
═══════════════════════════════════════════════════════════════════

1. Settings > Channels > Web Widget

2. Vous verrez un code comme :
   <script src="//code.tidio.co/abc123xyz.js" async></script>

3. COPIEZ la partie entre "tidio.co/" et ".js"
   Exemple : abc123xyz

4. Ouvrez le fichier : config/chatbot-ia-config.php

5. Trouvez cette ligne :
   define('TIDIO_ID', 'VOTRE_TIDIO_ID');

6. Remplacez par :
   define('TIDIO_ID', 'abc123xyz'); ← Votre vrai ID

7. Sauvegardez (Ctrl + S)
