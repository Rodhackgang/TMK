⚙️ PERSONNALISATION RECOMMANDÉE
═══════════════════════════════════════════════════════════════════

Connectez-vous au dashboard Tawk.to et configurez :

1. COULEUR DU WIDGET
   → Administration > Chat Widget > Customize
   → Couleur principale : #d4202c (rouge TMK)

2. MESSAGE D'ACCUEIL
   → Shortcuts > Welcome Message
   → "👋 Bienvenue chez TMK Foundation !"
   → "Comment pouvons-nous vous aider aujourd'hui ?"

3. PHOTO DE PROFIL
   → Settings > Profile
   → Téléchargez le logo TMK

4. HORAIRES DE TRAVAIL
   → Administration > Chat Widget > Working Hours
   → Définissez vos heures de disponibilité

5. STATUT EN LIGNE
   → Dashboard (en haut à droite)
   → Assurez-vous d'être "Online" pour recevoir les messages

═══════════════════════════════════════════════════════════════════
🛠️ POUR DÉSACTIVER LE CHAT
═══════════════════════════════════════════════════════════════════

Si vous devez désactiver temporairement le chat :

1. Ouvrez : config/chat-config.php
2. Changez : define('TAWK_ENABLED', true);
3. En : define('TAWK_ENABLED', false);
4. Sauvegardez

Pour réactiver, remettez true.
