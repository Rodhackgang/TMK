**Code d'intégration :**
```html
<script type="text/javascript">
(function(d, m){
  var kommunicateSettings = {
    "appId":"VOTRE_APP_ID",
    "automaticChatOpenOnNavigation": true,
    "popupWidget": true
  };
  var s = document.createElement("script"); 
  s.type = "text/javascript"; 
  s.async = true;
  s.src = "https://widget.kommunicate.io/v2/kommunicate.app";
  var h = document.getElementsByTagName("head")[0]; 
  h.appendChild(s);
  window.kommunicate = m; 
  m._globals = kommunicateSettings;
})(document, window.kommunicate || {});
</script>
```

## 🚀 Installation Recommandée : Tidio

### Étape 1 : Créer un Compte
```
1. Allez sur https://www.tidio.com
2. Cliquez "Start Free Trial"
3. Inscrivez-vous avec votre email
```

### Étape 2 : Configurer le Chatbot IA
```
1. Dashboard > Chatbots
2. "Create Chatbot" > "AI Assistant"
3. Nommez-le : "Assistant TMK"
4. Langue : Français
```

### Étape 3 : Entraîner le Bot
```
Ajoutez des réponses aux questions courantes :

Q: Qui êtes-vous ?
R: Je suis l'assistant virtuel de TMK Foundation, une organisation humanitaire au service des communautés défavorisées.

Q: Comment vous contacter ?
R: Vous pouvez nous contacter via WhatsApp au +243 978 219 845 ou par email à contact@tmkfoundation.org

Q: Quels sont vos projets ?
R: Nous intervenons dans les orphelinats, hôpitaux, écoles et centres d'accueil. Consultez notre page "Réalisations" pour voir nos actions.

Q: Comment faire un don ?
R: Contactez-nous directement pour connaître les modalités de don. Nous serions ravis de vous compter parmi nos bienfaiteurs !

Q: Où êtes-vous situés ?
R: TMK Foundation intervient principalement en République Démocratique du Congo.
```

### Étape 4 : Récupérer le Code
```
1. Settings > Channels > Install on website
2. Copiez votre code Tidio
3. Il ressemble à :
   <script src="//code.tidio.co/abc123xyz.js" async></script>
```

### Étape 5 : Intégrer sur Votre Site
```php
Ouvrez : utils/footer.php

Ajoutez AVANT </body> :

<!--Start of Tidio Live Chat Script-->
<script src="//code.tidio.co/VOTRE_TIDIO_ID.js" async></script>
<!--End of Tidio Live Chat Script-->
```
